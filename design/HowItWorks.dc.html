SECTION 02.3  /  COMMUNICATIONS

Four ways the data gets out.

LINK 01  /  PRIMARY

LoRa SX1276, 868 MHz

Kilometres of range with no tower and no subscription. This is how a chamber in a hill village reaches the FPO office.

LINK 02  /  FALLBACK

GSM SMS

If the chamber goes critical and LoRa is down, the alert still leaves as a text message.

LINK 03  /  SERVICING

Local Wi-Fi access point

A technician connects a phone directly to the unit for diagnostics, with no internet involved at all.

LINK 04  /  FARMER

Offline-first application

The app caches the last known state, so it opens and answers with no signal, then syncs when a link returns.
